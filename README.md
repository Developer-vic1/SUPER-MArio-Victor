# Super Mario Víctor — La última estrella (2D)

> Super Mario Bros is a platformer game developed and published by Nintendo for the NES game console. Players control Mario as they traverse the Mushroom Kingdom to rescue Princess Peach from Bowser. They traverse side-scrolling stages while avoiding hazards such as enemies and pits with the aid of power-ups such as the Super Mushroom, Fire Flower, and Starman.

- **Topics**: Physics, Level Design, Game Feel
- **Autor de esta adaptación**: Víctor · VictorDev.
- **Unity**: 6000.3.16f1 (Unity 6.3 LTS).
- **Campaña**: nivel 1-1 original completo → subterráneo → océano → castillo de los tres sellos → final original.
- **Controles**: A/D o flechas, Espacio para saltar/nadar y Escape para pausar. Las tuberías originales mantienen su tecla de entrada; el menú ofrece controles, música y animación reducida.
- **Ejecutable**: menú `Mario Victor → 2. Verificar y compilar Windows 64-bit`; entregar toda la carpeta `Builds/Windows64`.
- **Guía actual**: [Integración, pruebas, MCP y GitFlow](Docs/INTEGRACION_UNITY6.md).
- **Resultados de validación**: [Registro del 29 de octubre de 2026](Docs/VALIDACION_2026_10_29.md).

La base de este repositorio es el tutorial 2D de **Zigurous**. Se conserva su historial y el recorrido original, con la adaptación y las ampliaciones identificadas en commits propios.
